# Questions 
## Why Not A Discord Server For UniOS?
The reason there won't be an official UniOS Discord server is because Discord doesn't have end-to-end encryption and is 
centralize. This can comprise user privacy, which goes against the UniOS philosphy. Discord will also sell user data to 
third-parties, which Matrix does not do. For this reason, UniOS will just rely on Matrix and Mastadon for the user communication.
