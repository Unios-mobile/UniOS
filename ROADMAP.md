# Future Plans
- **Forum Page.** There is plans for a Forum page that will be on the UniOS website that will allow you to communicate and share your own creations with UniOS.
- **Matrix Server.** There is plans on making a Matrix server for UniOS to allow you to communicate with your own people.
    - For why it won't be a Discord server, please see the [FAQ](https://github.com/Unios-mobile/UniOS/blob/main/FAQ.md) file (this will be changed to a webpage when it is made)
- **Mastadon Page.** Plans for a Mastadon account are in the work and will be used to communicate the changes to the OS.
- **Website.** The first plan — after making the OS— is to have a website for the OS where you can download and use it.
